# Services

The Unbroken Chain platform is composed of the following services:

- **Extraction Service** — extraction pipeline.
- **Reader** — read-side service.
- **Writer** — write-side service.
- **UBC Control Plane** — orchestration and admin UI.
- **GitHub Gateway** — provider gateway for GitHub.

Each service contributes its own documentation from its in-tree `docs/` folder. Pick a service from the sidebar.
