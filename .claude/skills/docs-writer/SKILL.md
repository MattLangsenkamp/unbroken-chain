description: Use when writing documentation for services
---

This skill is for writing documentation that is for humans, but can also be consumed by agents. 

Markdown and portable assets are the golden path. Word docs and file formats that require a specific program are not.

good file formats (not exhaustive):
- SVGs
- Markdown
- JPEG (when SVG is not appropriate)
- mermaid diagrams

Do not overuse emojis. Its annoying

Do no write words for the sake of writing words. Every sentence should have a purpose. 

Bullet points are fine but don't overuse them. Prefer concise paragraphs.

Each service should have a docs folder associated with it. That is where you will find in depth explanation for that service.

If writing a sequence diagram is appropriate or requested refer to the types/sequence-diagram.md
